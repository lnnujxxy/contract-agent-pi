# Glossary

Canonical terms are the exported types and const arrays in `src/domain.ts`. If this list and that module disagree, the module wins.

| Term | Export |
| --- | --- |
| Contract type | `ContractType`, `CONTRACT_TYPES` |
| Risk level | `RiskLevel`, `RISK_LEVELS` |
| Contract file | `ContractDocument`, `ContractFormat`, `CONTRACT_FORMATS` |
| Chunk | `ContractChunk` |
| Finding | `ReviewFinding` |
| Report | `ReviewReport` |
| User instruction | `ReviewInstruction` in `src/review-instruction.ts` |

Tickets live in GitHub Issues.
